# موقع Vip X Store — أسعار حسابات ستيم

الموقع يسحب أرخص سعر لكل لعبة من G2G كل ساعة (حسابات ستيم جديدة، صفر ساعات، من بائعين تقييمهم عالي)، ويحسب السعر بالدينار:

```
سعر البيع = (سعر G2G × 1.0449 + 0.10) × 1585 + 5000   ← ويتقرب لفوك لأقرب 500
```

## التشغيل لأول مرة (مرة وحدة بس، 10 دقائق)

1. سوي حساب مجاني على **github.com**.
2. من فوك اضغط **+** ← **New repository**، سميه `vipx-store`، خليه **Public**، واضغط **Create**.
3. بالصفحة الجديدة اضغط **uploading an existing file** واسحب كل ملفات هذا المجلد (وبيها مجلد `.github` و`site`)، وبعدها **Commit changes**.
   - إذا مجلد `.github` ما انرفع (مخفي)، اضغط **Add file ← Create new file**، اكتب الاسم `.github/workflows/update.yml` والصق محتوى الملف.
4. روح **Settings ← Pages**، وبـ **Source** اختار **GitHub Actions**.
5. روح **Actions**، واضغط **I understand… enable**، بعدها **تحديث الأسعار ← Run workflow**.
6. بعد دقيقتين يطلع رابط موقعك بـ **Settings ← Pages**، شكله: `https://اسمك.github.io/vipx-store/`

من هنا وطالع يتحدث وحده كل ساعة.

## تغيير الإعدادات

كلشي بملف `config.json` (افتحه بـ GitHub واضغط القلم ✏️):

| الإعداد | المعنى |
|---|---|
| `usd_rate_iqd` | سعر الدولار عندك (1585 من تجربة الشراء) |
| `profit_iqd` | الربح على كل حساب (5000) |
| `round_up_to_iqd` | التقريب لفوك (500) |
| `g2g_fee_percent` / `g2g_fee_fixed_usd` | رسوم الفيزا بـ G2G (4.49% + 0.10) |
| `min_seller_satisfaction` | أقل تقييم للبائع (0.97 = 97%) |
| `min_seller_ratings` | أقل عدد تقييمات على العرض |

## إضافة لعبة

افتح `games.json` وضيف سطر مثل هذا:

```json
{"id": "minecraft-dungeons", "name_ar": "ماينكرافت دنجنز", "steam_name": "Minecraft Dungeons", "match": ["minecraft dungeons"]}
```

- `name_ar`: الاسم اللي يطلع بالموقع
- `steam_name`: اسمها بستيم (منه ينجاب الغلاف تلقائياً)
- `match`: كلمات لازم تكون بعنوان العرض بـ G2G

## منو البائع ورابط الشراء؟

بعد كل تحديث روح **Actions** ← آخر تشغيل، وبالأسفل جدول بيه لكل لعبة: سعر G2G، التكلفة عليك، سعر البيع، البائع، ورابط الشراء المباشر.
هذا الجدول ما ينعرض بالموقع للزبائن.

## إذا G2G حجب السحب

إذا شفت بالـ Actions رسائل "فشل" وما تحدثت الأسعار، الموقع يبقى على آخر أسعار صحيحة وما ينمسح. كلمني وأحوله لأداة سحب ثانية.
